# Агент за 1 день (LITE) — карта проекта

**Что это:** агент, который сам находит тему в соцсетях, делает по ней карусель,
пост-инфографику, гайд на вашем сайте, автоворонку в директ и вертикальный ролик,
а готовое присылает вам в телеграм на приёмку.

**Первая сессия:** наберите `/setup` — мастер всё установит и настроит.

---

## Команды агента

| Команда | Что делает |
|---|---|
| `/setup` | установка и настройка (один раз) |
| `/тренды` | ищет виральные темы в вашей нише, проверяет кодовое слово |
| `/реф` | разбирает референс: кадры, транскрипт, дизайн-код, проверка фактов |
| `/карусель` | слайды для Instagram и пост-инфографика |
| `/гайд` | страница-разбор на вашем сайте + две инфографики + деплой |
| `/воронка` | автоответ в директ на кодовое слово |
| `/рилс` | вертикальный ролик из вашего видео или из аватара |
| `/в-телеграм` | приём исходников и отправка готового на приёмку |
| `/конвейер` | всё перечисленное подряд, по одной теме |
| `/бэкап` | копия рабочего состояния в ваш приватный репозиторий, восстановление из неё |

Обычный день — одна команда: `/конвейер`.

## Карта папок

```
<корень>/
├── SETUP.md                # инструкция по установке (для человека)
├── CLAUDE.md               # этот файл
├── HANDOFF.md              # «где остановились» — читается в начале сессии
├── docs/                   # уроки для человека: установка, команды, рабочий день
├── styles/                 # стиль автомонтажа (в этой сборке один — «кинетик»)
├── .claude/skills/         # десять команд агента и антиклише-фильтр
├── scripts/                # движки: поиск, скачивание, слайды, монтаж, отправка
├── site/                   # сайт-витрина (Next.js), деплой на Vercel
├── workspace/
│   ├── registry.json       # реестр: тема, кодовое слово, форматы, статусы
│   ├── refs/<slug>/        # скачанные референсы и кадры
│   ├── carousel/<slug>/    # спеки и готовые слайды
│   ├── guides/<slug>/      # спеки инфографик
│   ├── reels/<slug>/       # части, сториборды, монтаж
│   └── assets/photos/author/  # ваше фото для генераций
└── auth/                   # профили браузера с вашими логинами (не пересылать!)
```

## Конфиги (создаёт `/setup`, лежат вне git)

| Файл | Что внутри |
|---|---|
| `scripts/.f2-brand.json` | бренд, хэндл, фото и описание внешности |
| `scripts/.niche.json` | аккаунты и хэштеги вашей ниши |
| `scripts/.hiker-config.json` | ключ для поиска и скачивания из Instagram |
| `scripts/.telegram-config.json` | токен бота и чат для приёмки |

| `.mcp.json` | ChatPlace (воронка) и HeyGen (аватар) |

## Правила работы

1. **Кодовое слово выбирается первым**, до слайдов и текста ролика. Проверять на
   пересечение с уже занятыми: воронка ловит слово по вхождению, и пересечение
   означает два ответа в директ одному человеку.
2. **Воронка создаётся только после того, как страница гайда отдала 200.**
3. **Макет карусели показывается до рендера.** Одна проверка дешевле восьми перегенераций.
4. **Ролики — по одному до приёмки.** Не собирать партию, пока предыдущий не принят.
5. **Промпты для видео — без hex-кодов, таймкодов и имён файлов:** модель впечатает
   их прямо в кадр. Цвет — словом, тайминг — словами.
6. **В тексте озвучки — без тире**, иностранные названия транслитом.
7. **Звук в финале ролика — от того, кто монтировал.** Подменять дорожку на исходную
   можно только по прямой просьбе: молчаливая подмена выглядит как «всё в порядке».
8. **Факты проверяются по первоисточникам.** Расшифровка ошибается в названиях,
   автор референса — в сути. В контент идёт только подтверждённое.
9. **Тексты в публикацию** прогонять через антиклише (навык `humaniser`) и проверять
   машинно: `python .claude/skills/humaniser/scripts/lint.py <файл>`. Есть СТОП —
   текст не публикуется.
10. **Секреты** (`auth/`, конфиги с ключами) не коммитить и не пересылать.
11. **Отчёт по факту, а не по намерению:** «готово» = проверено.

## Уроки

В `docs/` лежат уроки для владельца: установка, аккаунты и деньги, первый контент,
справочник команд, рабочий день, разбор частых сбоев. Если человек спрашивает
«как это делается» или «что мне сейчас нажать» — открой нужный урок и объясни
своими словами по нему, а не по памяти. Если реальность разошлась с уроком
(поменялся интерфейс сервиса) — скажи об этом прямо и предложи поправить файл.

## Точка останова

Начало сессии — прочитать `HANDOFF.md` и `workspace/registry.json`.
Конец сессии — перезаписать `HANDOFF.md` (что в работе, что заблокировано, следующий
шаг) и **сделать бэкап** (`/бэкап`). Сам агент восстановится из выданного репозитория,
а реестр, кодовые слова, гайды и точка останова — только из бэкапа.

## Обновления

**Эта сборка зафиксирована и не обновляется** — копия выдана один раз и живёт
у владельца своей жизнью. Если человек просит «обнови агента», не делай вид,
что обновление приехало: скажи прямо, что сборка спринта не обновляется, а новые
конвейеры и стили выходят в полной версии. Правки в свою копию человек, конечно,
вносит сам — это его репозиторий.
