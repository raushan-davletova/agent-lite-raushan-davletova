# Агент за 1 день (LITE) — установка

Этот пак разворачивает агента, который делает контент: находит темы, собирает карусели
и ролики, ведёт сайт с гайдами и автоворонку в директ. Установку ведёт сам агент —
ваша задача отвечать на вопросы.

**Время:** 40–60 минут, из них вашего активного участия около 20 —
остальное скачивается и ставится в фоне.

**Куда ставится:** Windows 10 или 11 — ваш компьютер либо арендованная машина.
Минимум 4 ядра, 8 ГБ памяти, 120 ГБ диска; комфортно — 8 ядер, 16 ГБ, 200 ГБ.
Windows Server не подходит. Про аренду есть отдельный раздел в
[уроке 01](docs/01-ustanovka.md#если-вы-ставите-на-арендованную-машину): где взять
Windows 10/11 в аренду и что отличается от работы за своим компьютером.

## Что подготовить

| Что | Зачем | Где взять |
|---|---|---|
| Подписка **Claude** (Pro или Max) | мозг агента | claude.com |
| Подписка **ChatGPT** (Plus и выше) | генерация слайдов и инфографик | chatgpt.com |
| Аккаунт **GitHub** | им же вход в Vercel | github.com (бесплатно) |
| Аккаунт **Vercel** | ваш сайт с гайдами | vercel.com, вход через GitHub |
| Ключ **Hiker API** | поиск тем и скачивание референсов | hikerapi.com |
| **Телеграм-бот** | приёмка готового контента | @BotFather, одна минута |
| Портретное **фото** | вы на слайдах | хорошее освещение, лицо крупно |
| (по желанию) **ChatPlace** | автоворонка в директ | chatplace.io |
| (по желанию) **HeyGen** | говорящий аватар в роликах | heygen.com |
| (по желанию) **Google-аккаунт** | автомонтаж роликов во Flow | генерации платные |

Без последних трёх агент работает — просто не будет воронки, аватара и автомонтажа.

## Шаг 1. Поставьте три программы (10 минут)

1. **VS Code** — https://code.visualstudio.com — окно, в котором вы будете
   разговаривать с агентом.
2. **Git** — https://git-scm.com/download/win, все настройки по умолчанию.
3. **Claude** — в VS Code откройте Extensions (иконка квадратиков слева), найдите
   **Claude Code** и установите. Затем нажмите значок Claude в боковой панели
   и войдите в свой аккаунт.

## Шаг 2. Скачайте агента (2 минуты)

Сначала примите приглашение на GitHub — письмо пришло на почту вашего аккаунта.
Затем в VS Code откройте терминал (**Terminal → New Terminal**) и вставьте команду
из сообщения бота:

```powershell
git clone <ссылка-из-сообщения> C:\studio
```

Ставьте именно в короткий путь латиницей (`C:\studio`) — без русских букв и пробелов,
часть инструментов на них ломается.

## Шаг 3. Запустите мастер (30–45 минут, из них ваших ~15)

**File → Open Folder** → `C:\studio`. Откройте панель Claude и напишите в чате:

```
/setup
```

Дальше мастер ведёт сам:

| Фаза | Что происходит | Ваше участие |
|---|---|---|
| Окружение | Node, Python, ffmpeg, Chrome | почти нет |
| Навыки | команды агента | нет |
| Бренд и ключи | бренд, ниша, фото, ключи, бот | отвечать на вопросы |
| Входы | вход в ChatGPT и (по желанию) Google Flow | войти в аккаунты |
| Сайт | ваш сайт на Vercel | завести аккаунт, назвать проект |
| Проверка | тесты, включая настоящую генерацию | смотреть |

После установки закройте VS Code и откройте снова — подхватятся команды и сервисы.

## Шаг 4. Первый контент

```
/тренды
```

Агент принесёт несколько тем — выберите одну. Дальше:

```
/конвейер
```

Он пройдёт всю цепочку и пришлёт готовое вам в бота на приёмку.

## Бэкап: подключите сразу

Мастер предложит это сам в конце установки, но знать стоит заранее. Сам агент
восстановится из репозитория, который вам выдали. А ваша работа — реестр тем,
занятые кодовые слова, сайт с гайдами, спеки каруселей и роликов — не восстановится
ниоткуда. Поэтому её копия держится **не на этой машине**: диск умирает, система
переустанавливается, арендованный сервер пропадает за неоплату вместе со всем,
что на нём лежало.

Нужен аккаунт на github.com и **приватный** репозиторий, имя любое. Даёте агенту
ссылку, говорите «подключи бэкап» — дальше в конце дня хватает фразы «сделай бэкап».

Ключи и логины туда намеренно не попадают: вместо них в бэкапе лежит список,
что понадобится ввести заново и где это взять. Если машина всё-таки умерла —
ставите агента на новую по этой же инструкции и говорите «восстанови агента
из бэкапа».

## Про обновления

Сборка спринта **зафиксирована**: вы получили свою копию, и она остаётся такой,
какой вы её настроили. Ничего не приезжает само и ничего не ломается под вами
посреди работы.

Новые конвейеры, стили и движки выходят в полной версии агента — она обновляется
у клиентов постоянно. Захотите перейти, напишите нам.

## Если что-то пошло не так

Опишите проблему прямо в чате с агентом — он читает свои же ошибки и чинит их сам.
Разбор частых сбоев — [docs/06-kogda-lomaetsya.md](docs/06-kogda-lomaetsya.md).
Если не помогло, напишите нам: приложите последние строки из окна и скажите,
на каком шаге остановились.
