# Урок 01. Установка

Ставим на Windows 10 или 11. Всё вместе занимает час, из них вашего активного
участия минут двадцать — остальное качается и ставится само.

Порядок такой: программы → скачать агента → мастер настройки. Ничего не пропускайте,
каждый шаг опирается на предыдущий.

**Что нужно от машины:** минимум 4 ядра, 8 ГБ памяти и 120 ГБ свободного диска.
Комфортно — 8 ядер, 16 ГБ, 200 ГБ. Меньше минимума можно, но сборка ролика займёт
машину целиком и надолго: видео рендерится процессором, а не видеокартой.

Windows Server не берите. Формально агент на нём заведётся, но там нет встроенного
установщика программ, браузер по умолчанию блокирует загрузки, и установка спотыкается
на каждом шагу. Нужна обычная десктопная Windows.

**Если ставите на арендованную машину** — сначала прочитайте
[последний раздел этого урока](#если-вы-ставите-на-арендованную-машину). Там про то,
где взять Windows 10/11 в аренду, и что отличается от работы за своим компьютером.

## Шаг 1. VS Code

VS Code — это окно, в котором вы будете разговаривать с агентом и видеть его файлы.

1. Откройте **https://code.visualstudio.com** и нажмите Download for Windows.
2. Запустите установщик. Все галочки оставьте как есть, только включите
   **«Add to PATH»**, если её предложат.

## Шаг 2. Git

Через Git вы скачиваете своего агента и им же сохраняете свои правки.

1. **https://git-scm.com/download/win** → установщик под 64-bit.
2. Установка со всеми настройками по умолчанию — просто «Далее» до конца.

## Шаг 3. Claude

Это мозг агента. Нужна подписка **Pro** или **Max** — без неё он работать не будет
(подробнее в [уроке 02](02-akkaunty-i-dengi.md)).

1. Заведите аккаунт на **https://claude.ai** и оплатите подписку.
2. Откройте VS Code, слева нажмите иконку **Extensions** (квадратики), в поиске
   наберите **Claude Code** и нажмите Install у расширения от Anthropic.
3. После установки в боковой панели появится значок Claude. Нажмите его и войдите
   в свой аккаунт — откроется браузер, подтвердите вход.

Если расширение не находится, поставьте Claude Code с **https://claude.com/claude-code**
и откройте его в терминале VS Code командой `claude` — работать будете так же.

## Шаг 4. Скачайте своего агента

В телеграм-боте вы получили две вещи: приглашение на GitHub и команду для скачивания.

1. **Примите приглашение.** Письмо от github.com пришло на почту вашего GitHub-аккаунта.
   Откройте его и нажмите Accept invitation. Без этого шага скачивание не пройдёт —
   репозиторий закрытый, он ваш личный.
2. В VS Code откройте терминал: меню **Terminal → New Terminal**.
3. Вставьте команду из сообщения бота, она выглядит так:

   ```
   git clone https://github.com/Ai-studio-claude/agent-lite-ВАШ-ЛОГИН.git C:\studio
   ```

4. Git попросит войти в GitHub — согласитесь, откроется браузер, подтвердите.
   Это делается один раз.

**Важно про папку.** Ставьте именно в короткий путь латиницей: `C:\studio` или
`D:\studio`. Русские буквы и пробелы в пути ломают часть инструментов, и это
всплывёт не сразу, а на третьем часу работы.

## Шаг 5. Откройте папку и запустите мастер

1. В VS Code: **File → Open Folder** → выберите `C:\studio`.
2. Откройте панель Claude и напишите в чате:

   ```
   /setup
   ```

Дальше мастер ведёт сам. Он поставит недостающие программы, спросит про ваш бренд
и ключи, поможет войти в нужные сервисы, развернёт ваш сайт и прогонит проверки.

Что он у вас спросит:

| Спросит | Зачем | Где взять |
|---|---|---|
| Название бренда и хэндл | подпись на слайдах и в постах | ваши |
| Портретное фото | вы на слайдах каруселей | хорошее освещение, лицо крупно |
| Аккаунты вашей ниши | по ним он ищет темы | 5–15 конкурентов и похожих блогов |
| Ключ Hiker API | скачивание постов из Instagram | личный кабинет hikerapi.com |
| Токен телеграм-бота | приёмка готового контента | @BotFather, одна минута |
| Вход в ChatGPT | генерация слайдов | ваш аккаунт, войти в открывшемся окне |
| Аккаунт Vercel | ваш сайт с гайдами | вход кнопкой «Continue with GitHub» |

Ключи он записывает в файлы, которые никуда не уезжают: они исключены из
репозитория и не попадут ни к нам, ни в git.

## Шаг 6. Перезапустите

Закройте VS Code и откройте снова. Это нужно, чтобы подхватились команды агента
и подключённые сервисы. После перезапуска напишите в чате `/тренды` — если он
принёс список тем, установка удалась.

## Если что-то пошло не так

Просто напишите об этом агенту в чат: «упало вот с такой ошибкой» и вставьте текст
ошибки. Он читает свои же ошибки и в большинстве случаев чинит сам. Не помогло —
напишите нам, приложив последние строки из окна и номер шага.

Три частые мелочи:

- **«claude не найден»** — не установлено расширение или не выполнен вход.
- **«git не найден»** — не поставлен Git или VS Code открыт до его установки:
  закройте и откройте заново.
- **Скачивание просит пароль и не пускает** — не принято приглашение с почты
  (шаг 4, пункт 1).

## Если вы ставите на арендованную машину

Машину в аренду берут ради одного: **автомонтаж роликов в Google Flow работает не из
любой страны**. В России он не работает совсем, в Европе и Британии формально
доступен, но загруженное видео там редактировать нельзя — а именно это делает команда
`/рилс` с вашей записью. Стабильно проходит США.

Что это значит при заказе:

| Параметр | Что брать | Почему |
|---|---|---|
| Система | **Windows 10 или 11** | легче и без лишних процессов; Windows Server тоже подойдёт, программы на нём ставятся так же |
| Страна | США | Европа не даёт редактировать загруженное видео |
| Город | Нью-Йорк, Сиэтл, Лос-Анджелес, Майами | не Чикаго и не Даллас — там местные законы режут часть функций |
| Мощность | 8 ядер, 16 ГБ, 200 ГБ | ролик рендерится процессором |

### Где взять Windows 10/11 в аренду

Нюанс, о котором лучше знать заранее: в прайсах хостингов почти всегда стоит
**Windows Server**, а не 10/11. Причина не техническая — правила Microsoft не
разрешают хостингам сдавать обычную домашнюю Windows как услугу. Рабочих путей три:

1. **Хостинг, у которого в списке систем есть Windows 10 или 11.** Такие есть, обычно
   это площадки, которые так и называются — «RDP-хостинг». Система идёт с пробной
   лицензией и предложением подставить свою. Самый быстрый и дешёвый путь; лицензию
   потом надо закрыть своей, иначе машина начнёт напоминать о себе.
2. **Свой образ.** Часть хостингов разрешает загрузить свой установочный образ.
   Ставите Windows 11 Pro и активируете купленным ключом. Ключ покупается один раз
   и переезжает с машины на машину.
3. **Выделенный сервер.** Дороже — от пяти тысяч рублей в месяц, — зато железо целиком
   ваше, ставите на него что хотите со своей лицензией, и рендер идёт заметно быстрее.

Если сомневаетесь, какой путь ваш, — спросите агента в чате, он разберёт варианты
под ваш бюджет.

**Проверьте площадку до того, как заплатите за месяц.** Почти все хостинги дают
почасовую оплату: возьмите самую дешёвую машину на час, зайдите на `labs.google/flow`
и **попробуйте загрузить туда любое видео**. Просто войти недостаточно — проверять
надо именно загрузку. Получилось — берите нормальную машину в том же городе у того же
хостинга.

**Не получилось — сначала просите сменить IP, а не меняйте площадку.** Напишите
в поддержку: «поменяйте, пожалуйста, IP-адрес, желательно из другой подсети» —
и повторите проверку. Страна остаётся правильной, а конкретный адрес мог оказаться
в чёрном списке Google. Смена адреса решает это чаще, чем переезд; город и хостинг
меняйте после двух-трёх неудачных смен.

### Если в форме заказа висит «нет свободных»

Скорее всего вы это и увидите: американские локации разбирают, и они регулярно
заканчиваются. Это состояние рынка, а не ваша ошибка. По порядку:

1. **Пролистайте все американские города в списке**, а не только тот, что открылся
   первым. Разбирают их неравномерно: Нью-Йорк занят, а Майами или Лос-Анджелес
   свободны. Нашли свободный — берите, вопрос закрыт.
2. **Спросите поддержку**, когда вернутся слоты и можно ли получить уведомление.
   Отвечают обычно в тот же день. Заодно попросите город вне Иллинойса и Техаса.
3. **Не готовы ждать — берите другую площадку.** Дороже, но с наличием спокойнее.

**Что выручает чаще всего.** Возьмите европейскую локацию на короткий срок и поставьте
агента на неё. Карусели, гайды, инфографики, воронки и телеграм-бот работают оттуда
полностью, а это большая часть вашей работы. Не будет только автомонтажа роликов
с заливкой вашего видео. Зато установка уже позади: когда освободится США, вы
переносите готовое бэкапом за час, а не начинаете с нуля.

### Что отличается от работы за своим компьютером

**1. Закрыли окно подключения — генерация встала.** Это главное. Агент работает через
видимое окно Chrome, а ему нужен живой рабочий стол. Если просто закрыть подключение
крестиком, экран блокируется, Chrome замирает, и ролик перестаёт собираться —
без ошибки, просто тишина. Перед тем как отключиться, выполните на машине:

```powershell
query session
tscon <номер вашего сеанса> /dest:console
```

Так рабочий стол останется живым. Если машина должна работать сама по ночам — попросите
агента настроить автоматический вход и отключить блокировку экрана, это надёжнее.

**2. Антивирус утраивает время установки.** Одна строка до запуска мастера:

```powershell
Add-MpPreference -ExclusionPath 'C:\studio'
```

**3. Диск кончается быстрее, чем дома.** Готовые ролики и кадры копятся, а диск
на арендованной машине обычно меньше. Раз в неделю скачивайте готовое к себе
и чистите рабочую папку.

### Google-аккаунт заводите прямо на этой машине

Не входите там в аккаунт со своего домашнего компьютера. Для Google это вход
с чужого адреса из другой страны — он попросит подтверждение, а может и временно
закрыть доступ. Заведите новый аккаунт здесь же и подписку оформляйте на него.

И отдельно: **подписка Google российской картой не оплачивается** — платежи Google
для карт российских банков отключены. Нужна зарубежная карта или сервис-посредник.
Аренда решает вопрос доступа, но не оплаты.
